# SK InterfaceDemo

Practice project demonstrating Python GUI elements using tkinter.

## Description

This project was written as a practice exercise in using Python and its related libraries.

Running the script displays basic GUI elements.

The intent is to begin with labels and images, then add demonstrations of buttons and text inputs.

## Getting Started

### Dependencies

* Python 3.13
  * tkinter

### Installing

* Program is available from its [Github page](https://github.com/SKent-wd/SK-InterfaceDemo).

### Executing program

* Run the file InterfaceDemo.py from the program folder.
* A window shows the demonstration output and interaction.
